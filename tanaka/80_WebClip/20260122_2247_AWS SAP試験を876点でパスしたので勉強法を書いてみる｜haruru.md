- 実務にあたりながら、DR対応やマルチアカウント環境、セキュリティ、モニタリング、CI/CDなど、インフラだけでなくSRE的な役割･スキルの必要性を感じ、AWSを活かしたより深いアプローチ･提案ができるようになりたいと思ったため

	- 期限切れ前になんとしても上位資格を取って延長したい!!(※もっと早く取り組みましょう)

## 学習してきたこと

### 2025/11下旬

- 実力を知るために [AWS Skill Builderのサンプル問題を解く](https://skillbuilder.aws/learn/8KM7DRV9BQ/official-practice-question-set-aws-certified-solutions-architect--professional-sapc02--/YUN6C9N454)
	- 正答率:7割
![画像](https://assets.st-note.com/img/1768041618-fcvOLRAy9TrVdU06Ih3pQ4ux.png?width=1200)

AWS SAP Official Question Set

### 2025/11下旬〜2025/12下旬

- **使用教材**
	- [AWS認定資格試験テキスト＆問題集　AWS認定ソリューションアーキテクト - プロフェッショナル　改訂第2版 (ＡＷＳ認定資格試験テキスト)](https://amzn.to/4qQ3W6s)
	- Gemini(思考モード)
- **学習方法**
	- 仕事後や入浴時間などの隙間時間を使いつつ読み進める
	- 実務で触っているサービスについては、把握してる内容が多かったため、サラッと流せる箇所もあった
	- 章末問題は章を読み終えたら必ず解くようにした
		- 章を読み終えた翌日に解いて、振り返りをして、その翌日に次章を読み進めるサイクル
		- 章末問題の解説や書籍の該当項目を読んでも消化不十分なところは、Geminiに解説をお願いした
			- プロンプトとして、 **AWS SAP-C02を学習していてサポートしてほしいこと、公式サンプル問題で7割であること、現在の実務経験を先にインプット** したものを利用している
			- 学習コーチのGem含めて、 **弱い分野や間違った問題などを相談すると、解説と合わせてミニテストを作ってもらえる点や、｢実務ではこういう事が多いけどこれってどうなの?｣などを対話して知識整理できる** のはとてもよかった
	- 書籍の巻末の模試は着手せずに残した

### 2025/12下旬〜2026/1初旬

- **使用教材**
	- [Cloud License:プロフェッショナルプラン](https://cloud-license.com/paid-membership-registration/)
	- [AWS BlackBelt資料](https://dev.classmethod.jp/articles/blackbelt-list/)
	- Gemini
	- [AWS認定資格試験テキスト＆問題集　AWS認定ソリューションアーキテクト - プロフェッショナル　改訂第2版 (ＡＷＳ認定資格試験テキスト)](https://amzn.to/4qQ3W6s)
- **学習方法**
	- Cloud License本試験モードを周回
		- 正月休みを使って、家の用事の合間の日中や夜など、2時間程度まとまって時間確保できるタイミングに集中して実施
		- とはいえ疲れた状態で長文問題75問を最後まで解くだけでも集中力がギリギリなので、見直し･振り返りは翌日行い、翌々日までかかることもあった
		- 明らかに理解不足なサービスは、BlackBelt資料や書籍、Geminiで概要から補填
		- 正答率:69%→73%→80%→85%→77%
			- 最後の77%は振り返りでケアレスミスがいくつかあったため、基本的には8割安定の理解度と判断
			- 回答時間は最終的に2時間前後で安定していた
	- 受験日の3日前〜前日の夜に残しておいた書籍巻末の模試を解き、振り返りを実施
		- 正月休み明けだったので、仕事後の就寝前に小分けにして解いた
		- 正答率:75%(75問かと思っていたら書籍の模試は82問あったw)

## 所感や今後

- アソシエイトレベルに比べて大規模かつ複雑な要件で、明らかに深い内容だった
	- 長文連続かつ75問の180分は普通にしんどかったです
		- Cloud License模試の周回が大変……
	- プロフェッショナルの名は伊達じゃないです
- 実務では恐らく関わる機会が限られる、オンプレからの移行や、世界規模システムのDRおよびパフォーマンス改善、マルチアカウント統制･NW設計などは、重点的にキャッチアップが必要だった
	- 日本では請求代行でAWSアカウントを利用している企業が多くある認識なので、AWS Control TowerやIAM Identity Center、Organizationsあたりはけっこう大変なのでは?と感じた
- 勉強する中で、実務で色々と足りていなかったところや、新しいアプローチや解決のアイデアの材料をたくさん得ることができた実感があり、やはりAWSの試験は良い試験だなと思った
- 資格取得前よりも要件やフェーズに応じた提案や現実的なステップの検討などができるようになった感覚はあるので、学んだことを実務で使いながらブラッシュアップしていきたい
- 次はAWS Certified DevOps Engineer - Professionalを取りたい
