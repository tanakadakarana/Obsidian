Claude Codeは、AI支援による開発体験を提供する強力なツールです。しかし、多くの機能が隠れているため、その真価を十分に活用できていないユーザーも少なくありません。この記事では、作業効率を大幅に向上させる実践的なテクニックを4つのカテゴリーに分けて紹介します。

## 1\. 必須ショートカット - 残業時間削減

### ①! 直接コマンド実行

`!git status` や `!npm test` のように、コマンドの前に `!` を付けるだけで、その結果を直接次の会話の文脈として渡すことができます。わざわざコピー&ペーストする手間が省けます。

**使用例:**

```text
!git status
```

実行結果が自動的に次の指示に引き継がれるため、「このステータスを見て次に何をすべきか教えて」と言う必要がありません。

### ② Escキーダブルタップで元に戻す

コードがぐちゃぐちゃになってしまった時、慌てる必要はありません。Escキーを2回素早く押すだけで、直前のチェックポイントに戻ることができます。後悔する前に、すぐにやり直せるのです。

### ③ Ctrl+R /Cmd+R で履歴検索

昨日使ったプロンプトを思い出せない？Ctrl+R/Cmd+Rを押せば、数秒で過去の履歴を検索できます。毎回同じことを入力する必要はありません。

### ④ @ でファイルを参照

特定のファイルについて質問したい時は、 `@` を入力するだけです。WeChatやSlackで人をメンションするのと同じ感覚で、ファイルを直接参照できます。コピー&ペーストは不要です。

**使用例:**

```text
@package.json の依存関係を更新して
```

## 2\. 知られざる便利機能-隠れ技

### ① /init - 自動ドキュメント生成

新規プロジェクトで `/init` コマンドを実行すると、CLAUDE.mdというプロジェクト説明書が自動生成されます。もう手作業でREADMEを書く必要はありません。

**実行方法:**

```text
/init
```

### ② Memory Updates - スマート記憶機能

「bunを使ってnpmは使わないで」とClaudeに伝えると、その設定が自動的にCLAUDE.mdに記録されます。次回からは自動的に対応してくれるので、毎回説明する必要がありません。

**使用例:**

```text
記憶して:このプロジェクトではbunを使用し、npmは使わない
```

### ③ Remote - どこでも作業を継続

ウェブ版でコーディングを始めて、帰宅後に続きを書きたい時、 `claude --teleport` コマンドでクラウド上の会話を「持ち帰る」ことができます。デバイスを切り替えても、完璧に作業を継続できます。

**実行方法:**

```bash
claude --teleport
```

### ④ /export - 会話を保存

重要な対話内容を `/export` コマンドで出力すると、自動的にMarkdownドキュメントが生成されます。後で見返したり、チームで共有したりするのに便利です。

**実行方法:**

```text
/export
```

## 3\. スマートアシスト機能 - Claudeをさらに賢く使う

### ① Ctrl+S/Cmd+S でアイデアを一時保存

入力途中で別のことを確認したくなった時、Ctrl+S/Cmd+Sを押せば現在の提案内容を保存できます。準備が整えば自動的に復元されるので、メモを取る必要はありません。

### ② Tabキーでスマート補完

Claudeはあなたが何を入力しようとしているか予測できます。灰色のテキストが表示されたら、Tabキーで受け入れるか、Enterで直接実行できます。タイピング量が大幅に削減されます。

### ③ 会話の随時復旧

PCの電源が突然切れたり、ターミナルを誤って閉じてしまった時でも心配いりません。 `claude --continue` と入力すれば、瞬時に前の会話が復元されます。作業内容は完全に保存されているため、何も失われません。

**実行方法:**

```bash
claude --continue
```

## 4\. 上級テクニック - エキスパートが使う会話管理術

### ① /rename - 会話に名前を付ける

`/rename api-migration` のように実行すると、現在の会話に名前を付けることができます。Gitのブランチのように管理できるため、必要な時に `/resume api-migration` で素早く切り替えられます。

**使用例:**

```text
/rename api-migration
```

後で再開:

```text
/resume api-migration
```

### ② /context - Token使用量の可視化

Token使用量が気になる時は、 `/context` コマンドを実行しましょう。Claudeが各部分の占有状況を詳細に表示してくれます。精度を保ちながらコストを管理できます。

**実行方法:**

```text
/context
```

### ③ /stats - 統計ダッシュボード

`/stats` コマンドで、自分の使用習慣を確認できます。最もよく使用したモデル、連続使用日数など、Githubのような感覚でClaude使用状況が可視化されます。

**実行方法:**

```text
/stats
```

### ④ /vim - Vimモードで効率アップ

`/vim` を起動すると、hjklでカーソル移動、ciwで単語修正など、Vimキーバインドが使えるようになります。キーボードから手を離さずに操作できるため、ギーク好みの効率的な作業が可能です。

**実行方法:**

```text
/vim
```

## まとめ

これらのテクニックを活用することで、Claude Codeの真の力を引き出せます。特に以下のポイントを押さえておきましょう:

- **日常作業の効率化**: `!`コマンド、 `@` 参照、Escダブルタップを使いこなす
- **プロジェクト管理**: `/init` 、Memory Updates、 `/rename` で整理された開発環境を維持
- **作業の継続性**: `-teleport` 、 `-continue` で場所やデバイスを選ばず作業可能
- **コスト管理**: `/context` 、 `/stats` で使用状況を把握

これらの機能を段階的に取り入れることで、確実に生産性が向上します。まずは普段の作業でよく使う機能から試してみてください。
