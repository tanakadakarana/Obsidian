## Claude Code on the webとは？

Claude Code on the webは、ブラウザやモバイルからGitHubと連携し、Claudeに開発を任せられるツールです。

今回はiOS版Claudeアプリの本ツールを利用しました。

## 年越しカウントダウン&おみくじアプリの開発

Claude Code on the webでは、まずあらかじめClaudeが操作するリポジトリを用意しておく必要があります。  
今回は新規プロジェクトのため、 `newyear-countdown-2026` というリポジトリを作成し、Claudeに連携させました。

その後、以下のような指示を投げました。

```
年納めとして、年末年始用の使い捨てイベントページを作成したい。

仕様:
- 2026年1月1日 00:00:00(JST)までカウントダウン表示
- 0時になったら自動で「あけましておめでとうございます」画面に切り替わる
- 新年画面におみくじボタンを表示
- おみくじは実際の神社のおみくじのようなイメージだけど、多少のユーモアは持たせたい
- 和風デザイン、適度なアニメーション演出
- GitHub Pagesで即ホスティング可能な形式
質問があれば先に質問して
```

「質問して」というフレーズ入れておいたため、「技術仕様について」、「おみくじの内容について」、「デザインについて」という質問は最初に返してきたのですが、その後自主的に新規リポジトリで空であることを確認した後、以下のデフォルト案を挙げてきました。

```
## デフォルト提案

技術構成:
- index.html に全て含める（CSS/JSインライン）でシンプルに
- GitHub Pagesで即公開可能
おみくじ仕様:
- 伝統的な7段階（大吉、中吉、小吉、吉、末吉、凶、大凶）
- 2026年の運勢を占う内容
- 軽めのユーモア（技術者向けネタも少し混ぜる）
- 何度でも引き直し可能
デザイン:
- 伝統的な和風（赤、金、黒を基調）
- 雪のパーティクル演出
- おみくじはスライドインアニメーション
- BGM/効果音なし（クリックだけでもっと手軽に）
レスポンシブ対応: スマホでも見やすく
この方向性で良ければすぐに実装開始します！変更点があれば教えてください。
```

提案内容で問題なかったため、この内容で承諾したところ数分程度で成果物が上がってきて、GitHub Pagesの設定としてデプロイしたいブランチを設定だけすればアプリを確認できる状態になりました。

結果として、成果物自体に大きな問題もなく、最初に上げた仕様通りのものが上がってきました。しかし、フォントサイズやスペーシング、雪の結晶の降るアニメーションの速度といった点は微調整が必要だったため、その調整やり取りは何度かやる形になりました。

調整するたびにPushして、動作確認して…というのを繰り返していたため思ったより修正に時間はかかってしまいました。

ただ、今回のことから開発の大枠については外出先からClaudeアプリで指示を出して進めさせ、修正作業は自宅に帰ってからPCでClaude Codeから(または直接自身で)進めるという使い分けが最適だろうと感じました。
